# Exercício módulo 13 — Notas de alunos

Cadastra alunos com nome, matrícula e notas de provas. Valida notas entre 0 e 10 e exibe os dados e a média de cada aluno.

## Conceitos praticados

Encapsulamento, arrays e cálculo de média.

## Como executar

1. Abra a pasta do projeto no IntelliJ IDEA.
2. Configure um JDK 17 ou superior.
3. Execute o método main da classe Main.
